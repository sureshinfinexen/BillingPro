{{ t('getting_started') }}

Follow the steps below in order. Download the PDF for printing / sharing.

{{ t('download_pdf_guide') }}

0. Start the app

  • Run START_BILLINGPRO.bat or python run.py
  • Open http://localhost:8003
  • Default logins: superadmin / superadmin123 · admin / admin123 · cashier / cashier123
  • Change passwords after first login (production)

1. Super Admin (new shop / features)

  • Shops / branches — add the shop
  • Features & admin — enable modules sold to that shop
  • Create a store admin for that shop

2. Store Admin — setup (do in this order)

  • Settings — shop name, GST default %, bill greeting, theme
  • Counters — billing counters (e.g. Counter 1)
  • Employees — add cashiers; link each to a counter
  • Assign pages — tick screens each cashier may use → Save
  • Suppliers — add vendors you buy from
  • Products — add items (or Excel/CSV upload); set MRP, cost, GST
  • Or open Sample templates → Load demo pack for instant test data
  • Purchases / GRN — receive stock from a supplier (qty + purchase rate)
  • Supplier templates (optional) — save monthly purchase lists; upload Excel; Receive into stock
  • Stock — verify quantities; adjust if needed
  • Warehouses / Batches (optional) — if those features are enabled
  • Loyalty / Coupons (optional)
  • Print barcode labels from Products if needed

3. Daily billing (cashier)

  • New Bill — scan / search product → pay (cash / card / UPI / split)
  • Held bills — pause and recall a bill
  • Bills — view, reprint, edit (if allowed)
  • Returns — return items / credit note
  • Credit (Udhaar) — credit sale and collections
  • Day close — end-of-day cash summary

4. Reports & tax

  • Dashboard / Reports — sales, profit overview
  • Shifts — counter / staff sales
  • GST export — CSV for returns
  • Audit log — who changed what
  • Reorder — low stock list

5. Menu map (left sidebar)

  • Overview — Dashboard, Reports, Shifts, Day close
  • Billing — New Bill, Holds, Bills, Returns, Credit
  • Inventory — Suppliers → Products → Purchases → Templates → Stock → Reorder → Warehouses → Batches
  • Customers — Loyalty, Coupons
  • Reports & tax — GST export, Audit
  • Administration — Settings, Counters, Employees, Assign pages, Shops, Offline
  • Help — this guide + PDF
